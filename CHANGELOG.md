# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-03-21

- Added a read-only multi-chain arbitrage scanner in Rust for Ethereum, Arbitrum, Base, and Polygon.
- Added SQLite persistence for opportunity events and cross-chain WETH price snapshots.
- Added Python analytics for summary tables and chart generation from captured session data.
- Added public repository metadata, CI guidance, and verification commands for contributor confidence.
